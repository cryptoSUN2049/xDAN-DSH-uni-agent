01 / 直接执行

专项目标：训练一个懂 DSH、会管理信息的小模型

新增深化专题：数据层、SFT、GKD／OPD与Agent long-loop RL，按最新d606851源码补充统一数据合同、教师接入与训练阶段。本页其余内容保留原审计快照。

以 Qwen3.5-4B 为学生模型，让它在 DSH 中可靠执行任务，并自主决定记什么、何时读取、怎样压缩、何时回源，以及怎样把工作交给新会话。

模型学策略

权重学习工具、记忆和context管理的决策规律；用户的具体事实保存在有scope与版本的外部存储。

DSH管真实状态

DSH拥有工具、文件、会话投影、权限与生命周期；训练器不能伪造状态，也不另造产品Agent loop。

Uni-Agent承接训练

复用Gateway token真值、typed TaskResult、严格准入、TransferQueue和配对verl；把新增能力接入同一条训练主线。

“优秀”要有独立证明

同任务、同预算、同Harness比较训练前后；新Session只能靠允许传递的记忆继续工作，不能暗带旧transcript或答案。

本专项包含完整方法路线与MiniCPM5-2B发布对标：DSH专长 → MemAgent式记忆基线 → SFT与任务级GRPO → 自主context编辑 → ContextPilot式关键节点分支与细粒度归因 → 跨Session和组合任务验收。分阶段交付不意味着把RL或ContextPilot核心降级为可选附录。

本页是基于代码审计的整改设计，拟议接口与文件均明确标注；本轮未实施产品改动、模型训练或远端部署。既有架构：Uni-Agent系统架构；模型依据：Qwen3.5-4B benchmark与优先级。

明确发布门槛，不以临时挑题决定胜负

  1. 专项模型门：预封存的DSH执行、memory、context三个track分别报告；建议主要macro成功率相对同DSH MiniCPM至少提高5个百分点，且paired 95%置信区间下界大于0，同时优于原Qwen。5个百分点是拟议目标，不是收益承诺；最终阈值与样本量根据校准方差和业务价值在test解封前冻结。
  2. 泛化门：预先指定一个公开Agent主评测和一组回归评测；公开主评测同条件显著胜出，回归落在预登记容忍区间。没有通过时仍可发布专项模型，但结论限定到真实通过的DSH任务；不得写“全面超过MiniCPM5-2B”。
  3. 证据门：用同任务paired比较；A/B链与task family作为聚类单位，不能把58行轨迹当58个独立任务。checkpoint由validation选，sealed test只作最终预定评估，量化候选重新评测。
  4. 交付门：发布base精确revision、adapter或可重建合并权重、tokenizer/template、DSH profile与工具版本、训练recipe、数据来源/许可/去污说明、评测脚本与完整失败统计、硬件和限制。建议候选名DSH-Qwen3.5-4B-Agent，正式名称在发布时确定。
接入现有SP计划：SP0即封存MiniCPM版本并跑共同环境基线；SP2—SP4围绕实际差距出题；SP5做方法消融；SP6同时完成三轨对标；SP7交付可重建模型包与model card。对标不是训练结束后再临时挑榜单。

03 / 方法取舍

借鉴 MemAgent 的记忆学习，完整吸收 ContextPilot 的决策训练

方法层真正有用的核心本专项怎么采用
MemAgent将长输入分段，每段更新紧凑memory；用最终任务表现监督此前的记忆生成。[U7] [U8]作为最小模型兼容与记忆学习对照；复用token链、数据适配和评估思想，保留独立baseline，不在DSH外包第二个循环。
ContextPilot工具层规划、结构化记忆、可回源的context卸载；模型主动管理工作上下文。先把最小动作真实接到DSH projection，再扩大工具集合；18个工具的数量不是验收目标。
ContextPilot采样层根据context变化和熵变化选择敏感决策，集中进行分支探索。先做可恢复状态和有界分支，再加入节点选择；总分支/attempt/token预算共享，不能随回滚重置。
ContextPilot归因层用经过某动作的后续分支结果估计该动作的贡献，改进粗粒度终奖广播。先保留vanilla GRPO对照，再验证branch价值与action advantage可复算；不把最终reward复制到每段称为细粒度归因。
DSH跨会话扩展前一会话的记忆行为，影响后一fresh Session能否完成任务。由controller冻结允许传递的artifact；B主动发现并读回；A/B使用同一冻结policy版本，等待整条链完成后再更新。

ContextPilot方法核对了论文方法章节和本地保留的上游代码来源。跨Session记忆训练是本项目扩展，需单独命名与验证，不对外声称未经证明的完整论文复现。MemAgent的53.5→58.0是旧Qwen3-4B的特定HotpotQA指标，不是Qwen3.5或DSH的当前成绩。[U11] [C2]

ContextPilot上游实现与DSH扩展要分别命名

机制固定上游oracle中的实际行为专项整改要求
节点敏感度uncertainty取前window token entropy之和（默认20）；entropy delta相对本条轨迹首次生成uncertainty，结合context delta。锁定窗口、参照点和权重；不改成相邻两步熵差后仍声称相同算法。
分支入口在管理动作之前保存状态，选择敏感动作的父节点重采样；剩余snapshot预算影响可分支数量。DSH必须恢复动作前真实状态；phase结束文件快照不能替代。

token loss论文按snapshot训练，并屏蔽前面snapshot已出现的输出，避免重复优化共享prefix。检查Gateway多chain与TQ现有mask是否满足该语义；有差异就新增显式适配与回归。

08 / 奖励与优化

奖励真正完成任务，并让早期记忆决策得到有效信号

资格先于reward

unfinished、错配、重放、证据篡改、不安全或不完整group先拒绝。合法且完成但策略失败可以reward=0，不应从训练记录中抹掉。

质量先于节省

主指标是任务完成/事实正确/有效恢复；节省token只能在质量约束满足后比较。避免通过删关键信息、缩短答案或拒绝工作骗取效率分。

先粗后细的学习路线

SFT建立合法动作与信息表示；vanilla GRPO建立真实结果反馈；再用同预算branch与credit消融证明ContextPilot新增机制的价值。

跨Session信用分配

同一candidate内A写记忆、B用记忆，生成期间冻结policy；最终链结果用于更新A/B动作。单独报告“写得对但没读”和“读了但没用好”的失败。

拟议阶段对照（相同数据、预算、模型初始化）
E0  Frozen model + 固定策略 / few-shot
E1  Verified SFT
E2  同一 E1 checkpoint → 任务级 vanilla GRPO
E3  同一 E1 checkpoint → partial rollout + 终奖基线
E4  同一 E1 checkpoint → partial rollout + subtree credit
    E2/E3/E4 独立训练、同总预算；逐级续训另记为产品迭代
E5  胜出方法迁移到 A→B memory chain 与组合任务

必须控制：candidate数 ≠ chain数 ≠ branch数 ≠ optimizer steps

对于含至少两个有效样本、采用均值中心化的GRPO组，同reward时相对优势为0。ContextPilot上游oracle对单样本组设mean=0、std=1，非零reward不满足上述结论；本专项须显式约束有效组大小。应先在训练/校准分布上找到模型偶尔能做对的难度；若普遍没有合法动作，先补真实示范/改任务合同，不能无限refill或放宽证据门禁制造样本。

分支采样优先级不能读取未来答案。熵、context变化和节点成本的定义必须对照固定上游代码；分支树、后代集合、reward、advantage、mask和实际训练权重要能从日志重算。全异步partial rollout解决调度效率，与这里的决策树分支不是同一机制。

工程可运行、模型有收益、产品可部署分别签收

门禁必须有的证据不能替代它的结果
代码与CPU合同实际类型、scope/版本、receipt、完整group、多chain、mask、重放/取消与错误路径测试。HTML写完、脚本打印出命令、inventory_passed。
模型训练正确性真实生成token/logprob；finite梯度；正确LoRA可训练张量发生变化；TQ消费crosswalk；独立进程reload。checkpoint文件hash变化、loss下降、只在同进程继续推理。
DSH专长未见任务/工具组合的执行成功率和恢复率；误调用/误拒绝/清理结果。背诵架构名词、照着给出的exact代码操作。
任务内记忆/context同任务与预算下完成质量；关键事实/关系/来源保留；需要时回源成功；token/时延。摘要越短越好、只测keyword包含率、只改可见UI没有改变真实request。
跨Session记忆B fresh Session主动发现并读回allowlist；正确更新失效事实；身份/scope与来源完备。自动注入全部A聊天记录、只恢复同一Session、把答案作为transfer内容。
ContextPilot方法完整动作前state恢复；节点选择与分支后代可重算；同预算vanilla/uniform/critical/credit消融。phase结束后snapshot、只复制prompt、把异步未完成rollout叫树分支。
效果与发布paired任务差值和不确定性；validation选checkpoint；sealed test固定评估；通用回归、成本与部署回退。几步更新、训练集reward上升、一个family反复测试。

停止规则须在启动前写进run manifest

  • 达到预登记的总attempt/group/branch/token/墙钟预算即停止；budget缺失不得进入自动长跑。当前文档不替用户填未经确认的GPU费用额度。
  • 出现NaN、错配/重放receipt、真实token不可追溯、不可恢复副作用、跨scope读取或基座误更新，停止该训练批次并保留证据。
  • 有效group不足或同组长期无reward差异，返回数据/难度/示范阶段；不能无界补样。
  • 主任务下降、合法请求被普遍拒绝或memory污染时，候选不晋升。数值容忍度与最小可检测收益需在sealed test解封前登记。
  • 效果不显著也要保留结果；小样本只能判工程与方向，不能承诺特定提升百分点或普遍超过更大模型。

12 / 我的判断

这次整改最该解决的，是策略动作与真实后果之间的断点

不要重做已有文件记忆

ActorFS、authority、fresh Session、transfer和source已经存在。最短路线是桥接这些能力到真实Gateway与训练身份，而不是再造一个Python记忆数据库或第二个Agent。

不要把摘要训练当成全部context管理

MemAgent的固定循环让模型主要学摘要内容。自主context管理还需要决定何时操作、操作哪段、何时回源；这些选择必须真正改变下一次模型输入。

不要把低分任务直接交给稀疏RL

Qwen3.5-4B有基础，但全部失败的group难以学习。先选偶尔成功且可验证的任务，逐步增加长度和组合难度；few-shot已解决的部分先算清内化收益。

不要用更大基础设施掩盖接口问题

单模型、单任务、小拓扑能最早定位错误。64卡默认recipe、Modal、Harbor和全异步各有价值，但不是本专项第一条有效学习信号的前置。

建议保留的长期结构：模型权重学习“如何管理信息”；DSH外部memory保存具体信息；context projection控制本轮看见什么；原始日志保存完整可追溯事实。三者分离，才能解释压缩、撤销、恢复与训练分别改变了什么。

风险最高的三个新增工程面

  1. DSH双入口统一：headless文件pilot与SDK训练入口的profile、authority、session身份不同。必须设计可控phase合同，不能靠字符串改名“连起来”。
  2. 多chain与分支训练权重：记录到了全部token只是第一步，必须确认一个更爱分段/分支的候选不会得到额外学习权重。
  3. context状态可恢复：操作改的是实际projection与工具/文件状态，不是离线文本。ContextPilot方法能否成立，首先取决于这些状态能否精确恢复和隔离。
