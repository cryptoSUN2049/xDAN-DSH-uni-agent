## 产物与成功定义

- `config.json`、`code/`、`code-manifest.json`：本次冻结配置与代码哈希。
- `pid`、`process.log`、`status.json`：进程、异常和状态。
- `output/screened.jsonl`、`output/three_teacher.jsonl`：完整结构候选池及三教师子池。
- `output/decisions.jsonl`：逐行保留、隔离、排除、重复及原因。
- `output/manifest.json`：原始输入和派生产物哈希、来源统计、领域及配额缺口。
- `report.md`：验收后的可读汇总。

状态顺序：STARTING → PREFLIGHT → PROCESSING → VERIFYING → SUCCEEDED。异常转 FAILED 并保留 traceback；非终态且 PID 消失显示 INTERRUPTED；心跳超过 60 秒标记 stale。不会自动重试或覆盖已有运行。

预检需要文件系统空闲至少 max(10GiB, 输入字节×4)，这是文件系统统计，不代表 Runpod 私有配额保证。完成后重新计算产物大小/SHA256并检查来源计数守恒。

**SUCCEEDED 仅表示结构筛选及文件验收成功，training_ready=false。** 20K 任一领域配额不足则不生成20K文件。正确性、俄语完整识别、近重复、模板与监督mask、token预算仍需后续验收。
