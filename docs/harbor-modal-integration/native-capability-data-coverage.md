## 分批准入

1. 四例诊断只验证动作、评分与失败分类，先跑通真实接口。
2. 每能力探索试训以约12 train/4 dev/4独立保留实例作为预算起点；按结构模板、依赖组合、冲突/失败机制划分，不能仅改字符串。正式封存须先建立访问隔离，未建立不称sealed。
3. 依据pilot错误率与方差扩展评估，冻结指标后再判断样本规模；上述数字不是行业统一阈值或效果保证。
4. 逐批记录独立任务数、rollout数、完整组数、奖励分布、消费率、非零更新、独立reload结果。12题×n4是12任务/48轨迹。
5. 全0奖励、已满分或动作不可达时先诊断，不能靠重复采样/增加训练步数宣称有价值的学习。

最短主线：DSH调度与文件证据baseline → 真实A/B记忆评估及训练归属 → 真正context操作 → 受控RSI。保持DSH唯一Agent Loop，Harbor后置。
