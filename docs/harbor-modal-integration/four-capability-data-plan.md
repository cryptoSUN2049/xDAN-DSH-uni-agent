# 四类能力的数据与在线RL任务计划

2026-09-09，用户已确认方向。当前优先单卡异步性能对照，以下数据计划保留并推进原型审计；不是144条数据已生成的声明。

| 能力 | 首批三类结构 | 核心验收 |
|---|---|---|
| DSH调度 | 能力发现；定义/调用/清理；依赖诊断与恢复 | 真实调用与产物正确、遵守约束 |
| 记忆 | 交接续作；索引定位；新旧事实更新 | A写入→新B检索，最新事实驱动最终任务 |
| 上下文 | 证据offload；真实compact保真；失效索引恢复 | 预算内继续任务、证据可追溯，不以压缩token数作成功 |
| RSI | 缺能力受限扩权；无收益保持；回归拒绝/回滚 | 候选合法、同预算实测收益、父状态与失败记录完整 |

每类3结构，暂预算24训练/6开发/6封存测试，共144独立任务。此为试验建设预算，不是充分训练或行业最低量。隔离场景/结构变体及实例，重复采样不增加独立任务数。测试封存不参与调提示、奖励或选择checkpoint。

每任务记录task_id/family/structure/split/version、固定初始文件与DSH权限、目标产物、阶段可见性/预算、verifier版本与环境hash。模型在线生成轨迹；任务数据不预写可冒充在线采样的答案。分项评分与终态结果分别保存，确保工具、记忆、上下文、候选失败可归因。普通合法失败保留零奖励；证据损坏不准入。
