系统打通程度：单独记录的证据向量

它不是可以自由选择的训练超参数。每个实验组合分别记录安装、真实执行、评分/轨迹准入、参数更新、独立reload、效果评估、性能评估的状态：未测/通过/失败/阻塞，并链接run ID和报告。某个组合通过，不自动覆盖另一个组合。

当前配对版本CPU回归通过；新GPU环境仅只读核验，未安装完整依赖。历史训练证据属于历史版本；Harbor、OPD、跨会话奖励与动态Harness训练各有独立缺口。

依赖与不可用组合

  • 当前DSH teacher接口不支持即用OPD，先完成接口与teacher信号契约。
  • MemAgent现有训练recipe默认8GPU，单卡需要适配；保持DSH唯一执行循环。
  • A→B终局奖励不自动归因到A写入；跨会话链与训练样本必须显式关联。
  • 动态Harness与权重同时变化时做2×2归因；候选搜索、选择验证与最终测试分开。
  • 树分支partial rollout与异步分段partial rollout分别记录身份，不因名称相同而共用实现假设。
