# 夜间实验分析与验收边界

本轮短序列教师评分兼容、独立一步冒烟、正式16步训练与全部checkpoint重载评测均已完成。七版本各30条输出已逐条核验身份、预算与重评分。最终step16比原版多通过一道数学题；证据不支持“全面能力提升”或“OPD无效”的结论。

## 已验证的工程环节

- Qwen3.8-27B 教师对 3 条真实学生短续写的原始 token ID 评分通过既定门禁：参考评分与 vLLM 评分的平均绝对误差 0.01044、P95 0.07962，阈值分别为 0.1、0.5。这是短序列、关闭 thinking 的限定验收，不是长上下文或全部工具模板兼容证明。
- 独立 `smoke-step1` 的 LoRA 已实际重载，`adapter_reload_verified=true`，权重 SHA256 为 `6735b4e27cc8a2d622692ee5944a4d989cd76f1b530b9b860447a4cef2083ff8`。冻结 v2 验证集生成完成 30/30，基础设施失败 0。重载成功与生成完成不等于 30 题全部回答正确。
- 算法为多领域单教师 OPD：学生在线采样，教师提供 token logprob；`k1 + policy gradient`，任务奖励不参与损失。不是多教师 MOPD，也不是使用固定示范答案进行 SFT。
- 冒烟与正式训练均从原版学生分别开始。冒烟不是正式训练的第 1 步；正式 16 步含预热，最多 15 次非零学习率更新，不能报告为 16 次有效更新。

## 数据质量整改及尚存缺口

原候选集为 160/40。对数学与科学共 80 条逐题复审，数学保留 28、排除 9、存疑 3；科学保留 4、排除 15、存疑 21。问题包含错误参考答案、多个正确选项、缺少必要条件，以及证明型问题被数值评分器错误接纳。严格策略排除所有存疑和不合格记录，保留原切分，得到 v2 的 122/30。此类问题属于数据与评分契约缺陷，不是 GPU 或模型故障。

## 保留的失败记录与禁止结论

- FlashInfer sampler 的 CUDA 编译目标检查失败已通过 native sampler 配置绕开；初次训练因专用环境缺少所请求的 FlashAttention2 失败，改为 SDPA 并保留 padding。首次失败未产生训练 checkpoint，应保留为基础设施记录。
- v1 上 1024 token 的旧评测仅是诊断证据，不能与 v2 上 4096 token 的正式评测比较，更不能把预算变化造成的差异归因于训练。
- loss 下降、梯度非零、adapter 重载均不是能力提升证明；教师规模更大也不证明其每个领域均优于学生。
- 关闭 thinking 的本轮不能声称验收了长链 thinking；无工具评测不能声称验收了 SWE/Agent 工具能力。
- W&B 当前为 offline。步数与时间有界不等于基于验证退化的自动止损；纯 OPD 也不能套用 GRPO 全对/全错组的零优势规则。
