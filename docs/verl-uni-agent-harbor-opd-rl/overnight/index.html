# 夜间实验口径

本轮是单教师、多领域、文本 OPD 探索试验：Qwen3.8-27B 教师与 Qwen3.5-9B 学生。不是多教师 MOPD，也不是静态教师答案 SFT。

## 实际配置

- 学生自行采样；教师对学生 token 序列提供在线 logprob。VERL 配置为 `loss_mode=k1`、`use_policy_gradient=True`、`use_task_rewards=False`。
- LoRA rank16/alpha32，学习率1e-6。独立冒烟1步关闭预热，确保真实更新；正式16步预热2步，首步学习率为0，因此最多15次非零学习率更新。
- 训练 batch8，单轨迹，temperature0.8，prompt上限2048、response上限1024。关闭thinking模板；不宣称覆盖长链thinking训练。
- 训练内验证预算1024，仅作过程诊断。正式独立评测固定v2验证集、greedy、4096输出token，所有模型相同工具条件（无工具）和学生模板。
- 独立smoke从原版开始；正式run也从原版开始，smoke不是正式第1步。两者checkpoint单独标识。

## 数据与评分边界

v1候选160/40经过实质复审后冻结v2为122/30；原始记录与原split未改写，只排除不符合准入要求的记录。领域分布为math23/5、instruction32/8、knowledge3/1、code32/8、chat32/8。知识域不足以判断收益。

数学验证最终数值；指令遵循仅验证支持的格式约束；知识选择题验证选项。代码只作语法诊断，聊天未作质量打分，两者不计综合准确率。VERL内部必须提供数字奖励而使用的0占位，不能解释为能力0分；该奖励不参与本轮OPD损失。

## 成功条件

兼容实测通过、实际非零权重更新、checkpoint完整且可重载、原版/教师/所有实际有效checkpoint同口径评测，并交付包含失败与局限的HTML。完成工程闭环不等于证明全面能力提升。

初始化时间与训练步时间分别统计；W&B为offline。当前是步数与时间有界运行，尚未建设基于验证退化的自动止损策略。

# 夜间实验分析与验收边界

## 保留的失败记录与禁止结论

- FlashInfer sampler 的 CUDA 编译目标检查失败已通过 native sampler 配置绕开；初次训练因专用环境缺少所请求的 FlashAttention2 失败，改为 SDPA 并保留 padding。首次失败未产生训练 checkpoint，应保留为基础设施记录。
- v1 上 1024 token 的旧评测仅是诊断证据，不能与 v2 上 4096 token 的正式评测比较，更不能把预算变化造成的差异归因于训练。
- loss 下降、梯度非零、adapter 重载均不是能力提升证明；教师规模更大也不证明其每个领域均优于学生。
- 关闭 thinking 的本轮不能声称验收了长链 thinking；无工具评测不能声称验收了 SWE/Agent 工具能力。
- W&B 当前为 offline。步数与时间有界不等于基于验证退化的自动止损；纯 OPD 也不能套用 GRPO 全对/全错组的零优势规则。
