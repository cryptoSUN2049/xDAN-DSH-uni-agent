## 为什么看起来一直没有训练

1. 验收仅C3→C4一个新增step，完整启动成本没有被长训练摊薄。
2. 原生trainer_base.py在fit才创建Tracking（409行），在step、保存、dump、TQ清理后才logger.log（500行）。因此初始化没有run，长采样期有run但没有history是这条路径的真实行为。
3. separate_async把trainer和standalone rollout分到不同资源池；首组完整轨迹到齐之前trainer等待。仅一组验收无法形成持续异步流水线，更不保证两卡同时高利用率。
4. 进度汇报沿用旧初始化快照，没有及时取得当前终态。应按实际阶段和更新时间汇报，不能以“running/无错误”等同训练健康。
