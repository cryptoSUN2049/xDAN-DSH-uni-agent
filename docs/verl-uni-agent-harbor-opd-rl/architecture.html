2. 一次 rollout 的时序

sequenceDiagram
  autonumber
  participant FW as Agent Framework
  participant GW as Gateway

  participant V as verifier
  participant E as vLLM
  FW->>GW: 开 session（group_uid, sample_index）
  FW->>H: harbor trial start --agent terminus-2 --env modal --model hosted_vllm/…
env: HOSTED_VLLM_BASE_URL=/sessions/id/v1
  H->>M: 创建沙箱（task image, 2 cpu / 4 GB）
  loop 每轮（≤ max_turns，episode ≤ max_total_tokens）
    H->>GW: POST chat/completions
    GW->>E: 转发，记录 prompt/response token + logprob
    E-->>GW: 生成
    GW-->>H: 文本
    H->>M: 执行命令
    M-->>H: 终端输出
  end
  H->>V: 起 verifier 沙箱跑 tests
  V-->>H: result.json（reward 0/1）
  H-->>FW: HarborCLIResult + reward
  GW-->>FW: trajectory.json / .npz
  FW-->>FW: mask_unfinished_episode · require_verifier_reward
